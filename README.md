# Math for ML Lab

My hands-on journey through **Mathematics for Machine Learning**, combining programming exercises, mathematical foundations, Jupyter notebooks, and practical implementations.

This repository serves as my personal learning workspace for developing the mathematical and programming skills needed to understand how machine learning algorithms work.

## 🎯 Objectives

- Strengthen my Python programming skills through practical exercises.
- Build a solid foundation in the mathematics behind machine learning.
- Practise solving problems and implementing concepts from scratch.
- Document my learning, mistakes, insights, and progress.
- Develop the foundations needed for deeper study in AI and machine learning research.

## 📚 Learning Roadmap

- [ ] **Python Fundamentals** — functions, loops, conditionals, lists, recursion, and problem-solving.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Tioluwanim/math-for-ml-lab.git
cd math-for-ml-lab
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the tools for working with notebooks:

```bash
pip install jupyter numpy matplotlib
```

Start Jupyter Notebook:

```bash
jupyter notebook
```
